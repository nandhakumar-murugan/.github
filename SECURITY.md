# Security Policy

## Supported Versions

We actively maintain and provide security patches for the latest released versions of all repositories in this organization.

| Project / Version | Supported          |
| ----------------- | ------------------ |
| Latest Main / Tags | :white_check_mark: |
| < Latest Release   | :x:                |

## Reporting a Vulnerability

We take the security of our open-source software and user data very seriously.

If you believe you have found a security vulnerability in any project maintained by **Nandhakumar Murugan (smnk-infotech / Prema AI Labs)**, please follow these responsible disclosure guidelines:

1. **Do not create a public GitHub Issue** for security vulnerabilities.
2. **Email the maintainer directly**:
   - **Primary Security Email**: [`smnk2006@gmail.com`](mailto:smnk2006@gmail.com)
   - **Institutional Contact**: [`24ucy129nandha@kgkite.ac.in`](mailto:24ucy129nandha@kgkite.ac.in)
3. Please include:
   - Repository name and affected file(s)
   - Detailed description of the vulnerability (e.g. CWE type, vector)
   - Step-by-step Proof of Concept (PoC) or reproduction steps
   - Potential impact assessment

### Response Timeline
- **Initial Acknowledgment**: Within 24 hours
- **Triage & Status Assessment**: Within 72 hours
- **Patch Release & Security Advisory**: Within 7-14 business days

Thank you for helping keep our open-source software and developer ecosystem safe!
